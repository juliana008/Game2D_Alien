# Game2D_Alien
Projeto realizado em aula durante a disciplina AQS

## Testes automatizados

Instale o pytest no ambiente do projeto e execute os testes a partir desta pasta. A suíte
cobre o movimento e os limites da nave, além da extensão `FastAlien` na frota:

```powershell
python -m pip install pytest
python -m pytest -v
```
